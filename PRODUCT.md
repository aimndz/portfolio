# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary**: Technical recruiters and engineering hiring managers evaluating candidates for full-stack software engineering roles. They scan quickly (often 30–60 seconds initially) to verify technical depth, production readiness, architectural competence, and code cleanliness.
- **Secondary**: Fellow developers, collaborators, and clients seeking technical partnership or reviewing open-source contributions.

## Product Purpose

- Showcase Amiel Ian Mendoza's end-to-end full-stack development skills and creative engineering capabilities.
- Convert recruiter and hiring manager visits into interview requests, technical discussions, and career opportunities.
- Provide rapid, low-friction access to deployed applications, source code repositories, resume, and direct contact methods.

## Positioning

- **Full-Stack Developer with an Artist's Foundation**: Approaches software engineering the same way as art—where structure, clarity, composition, and user expression matter as much as computational efficiency.
- **Demonstrated Production Craft**: Backed by flagship products with tangible utility and technical depth (e.g., All3Rounds battle rap community archive, Articuli speech evaluation platform), rather than boilerplate tutorial projects.

## Operating Context

- Viewed on desktop monitors and mobile devices by busy recruiters reviewing applications from job boards, LinkedIn, resumes, and GitHub profiles.
- Evaluated in fast triage situations where initial layout clarity, fast performance, and immediate scannability dictate whether the visitor dives deeper into project case studies.

## Capabilities and Constraints

- **Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide icons, and Radix UI primitives.
- **Theme Support**: Built-in high-contrast theme engine supporting Dark mode and Light mode.
- **Data Source**: Single source of truth in [src/data/portfolio.ts](file:///e:/dev/portfolio/src/data/portfolio.ts) driving profile info, experience, skills, and project catalog.
- **Constraints**: Must maintain fast load times, excellent Core Web Vitals, zero hydration bugs, and full mobile responsiveness.

## Brand Commitments

- **Identity**: Amiel Ian Mendoza (`aimndz`), based in Cavite, Philippines.
- **Voice**: Authentic, grounded, articulate, and creative; developer-forward without corporate fluff.
- **Assets**: Authentic profile photograph (`/images/me-img.png`), project showcase screenshots in `/public/images/projects/`, and live Google Drive resume.

## Evidence on Hand

- Production web projects with live URLs and GitHub repositories: All3Rounds (`all3rounds.com`), Articuli, Bliss & Flair, Propertize, ThisIsWhereYourTaxesGo, Furfeit (game jam), and Scratch-a-Date.
- Work experience and internship records (Founder / Full-Stack Developer at All3Rounds; Multimedia Intern at Zhiyuan Enterprise Group).
- Verified GitHub activity and codebase history under `aimndz`.

## Product Principles

1. **Proof Over Assertion**: Put functional, deployed software and real repositories front and center; show concrete engineering rather than self-proclaimed titles.
2. **Craft at Every Layer**: Treat code structure, UI aesthetics, interaction micro-details, and backend logic with equal artistic intentionality.
3. **Zero-Friction Access**: Ensure resume, GitHub repos, live demos, and direct email contact are accessible within a single click from any point on the page.
4. **Authenticity & Character**: Let creative personality show through interactive touches and genuine voice without getting in the way of high-speed recruiter scannability.
